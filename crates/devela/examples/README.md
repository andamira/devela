# devela examples

Small programs exploring different parts of devela.

Some demonstrate a single abstraction; others bring several parts together
to explore platforms, interfaces, and applications.

## Explore

- `code`, `data`, `num` — focused examples of language utilities, data structures, and numerical abstractions.
- `lang`, `media` — language, text processing, and media experiments.
- `run` — runtime and cross-platform experiments.
- `sys` — system interfaces, environments, and platform-specific functionality.
- `ui` — terminal, graphical, and web interfaces.
- `work` — execution and concurrency examples.

Individual directories may contain their own instructions, dependencies, and build scripts.
